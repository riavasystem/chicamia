# Chica Mia

Landing page cinematográfica para Chica Mia — juegos y experiencias para eventos (toro mecánico, cámara 360, reloj derribador).

Ver `CLAUDE.md` para la especificación completa del proyecto y `avances.md` para el estado actual y los próximos pasos.

## Stack

- Next.js (App Router) + React + TypeScript
- Tailwind CSS v4
- GSAP + ScrollTrigger, Lenis (smooth scroll)
- Deploy en Vercel (plan gratuito), sin backend propio

## Desarrollo

```bash
npm install
npm run dev
```

Abrir [http://localhost:3000](http://localhost:3000).

## Scripts

```bash
npm run dev     # servidor de desarrollo
npm run build   # build de producción
npm run lint    # eslint
npx tsc --noEmit  # typecheck
```
